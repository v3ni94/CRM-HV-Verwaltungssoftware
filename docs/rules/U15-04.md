# U15-04 Inhaltsmodus der Benachrichtigungsmails

- ID: U15-04
- Geltungsbereich: Sammelmail des Jobs `send_pending_mails` (`mhvp.workspace.notification_prefs`), je Mandant.
- Regel: Der Mandantenschalter `notification_mail_content` (Ablage im JSON `tenant_settings.sources`, keine Migration) steuert den Mailinhalt. `voll` (Standard, bisheriges Verhalten) sendet Titel und Text. `hinweis` sendet nur die Anzahl der neuen Benachrichtigungen und einen Link ins CRM, ohne Titel und Text. Ungültige Werte werden mit 422 abgelehnt; Änderung per `PATCH /tenant/settings` mit Recht `tenant_settings:update`, protokolliert im Änderungsereignis.
- Quellenstatus Anhang C: Produktschutz (Datenminimierung), keine Rechtspflicht behauptet. Die Wahl des Modus je Mandant ist eine Datenschutzentscheidung (OPEN_QUESTIONS U15-05).
- Abnahmefall: `tests/integration/test_q11_workspace_w3.py::test_notification_mail_content_mode_hint`, `NotificationMailContent.test.tsx`.
- Änderungsgrund: Review W45 (U15-04), Benachrichtigungstexte können personenbezogene Daten enthalten.
