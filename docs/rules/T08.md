# T08: Zustellung der Benachrichtigungsmails (M23-04)

- ID: T08
- Geltungsbereich: Mail zu Benachrichtigungen nach Benutzereinstellung, Mandant, je Benutzer.
- Quellenstatus: Produktschutz, keine Rechtsgrundlage (Anhang C nicht betroffen).
- Regel: Je Art wählt der Benutzer Sofort oder Täglich. Sofort wird vom Beat alle 5 Minuten, Täglich vom Lauf um 07:30 Uhr gesendet. Je Benutzer und Lauf entsteht eine Sammelmail. Versand über das Standardpostfach des Mandanten, Fehler bleiben offen. Stummschaltung wirkt beim Anlegen, Pflichtarten sind nie per Mail abschaltbar.
