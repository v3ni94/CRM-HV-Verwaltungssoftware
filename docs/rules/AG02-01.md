# AG02-01 Führendes System je Rechtsträger, Objekt, Vorgangstyp und Gültig-ab

- ID: AG02-01
- Geltungsbereich: Buchhaltung, Tabelle `ledger_leading_switch`, Prüffunktion `mhvp.accounting.leading.is_leading`, Sollstellungslauf, Mahnlauf, Lastschriftlauf, Zahllauf, automatische Bankbuchung; Routen `GET/POST /accounting/ledgers/{ledger_id}/leading-switches`, `POST .../leading-switches/{switch_id}/decide`
- Anforderungstyp: Fachliche Umsetzung (Abschnitt 13.1 Ergänzung, 6.9.10) und Produktschutz
- Quellenstatus Anhang C: keine Rechtsnorm herangezogen
- Regel: Je Buchungskreis, optional je Objekt, gilt für die Vorgangstypen Sollstellung, Mahnung, Lastschrift und Zahlungsauftrag die neueste freigegebene Umschaltung mit Gültig-ab bis zum Stichtag; eine Objektzeile geht der Buchungskreiszeile vor. Ohne freigegebene Umschaltung gilt `ledger.leading_system` unverändert. Im Sollstellungslauf sperrt nur eine ausdrückliche Umschaltung auf das Altsystem (bisheriges Verhalten mit Vergleichsbuchung bleibt, M10-05). Eine Umschaltung beantragt eine Person, entscheiden muss eine andere (keine Plattformadministration); die Freigabe der Plattform als führendes System verlangt G1 mit Objektkontext. Freigegebene Zeilen werden nicht geändert, eine spätere Umschaltung ist eine neue Zeile.
- Standard: keine Zeilen, Verhalten wie bisher; G1 geschlossen
- Abnahmefall: tests/integration/test_ag02_leading_switch.py (Vier Augen, G1, Mandantentrennung, Rechte, 422, Auflösung Objekt vor Buchungskreis und Gültig-ab)
- Änderungsgrund: Lückenbefund GAC-05 (Welle 18, AG02); Entscheidung A17 und M10-05 bleibt offen
