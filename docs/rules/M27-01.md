# M27-01 Preisstruktur ohne Beträge, Angebot als Entwurf

| Field | Content |
| --- | --- |
| ID | `M27-01` |
| Title | Preismodell als konfigurierbare Struktur (Stufen nach Einheiten, Zusatzmodule, Testphase) ohne vorbelegte Beträge; Angebot nur als PDF-Entwurf |
| Scope | Plattformebene (keine Mandantendaten), nur Plattformadministratoren; betrifft die Lizenzierung von Drittmandanten (Gate G5) und die Abrechnungsvorschau aus `mhvp.platform.licensing` nicht |
| Source status | Keine Rechtsnorm im Quellenregister (Anhang C); Produktschutz nach Regel 0.1.3 (keine erfundenen Zahlen). Beträge, Stufengrenzen, Umsatzsteuer und Rechnungsstellung sind Betreiberentscheidungen (`docs/OPEN_QUESTIONS.md` M27-01, M27-01-01) |
| Acceptance case | keine in Anhang D; Test `apps/api/tests/integration/test_m27_market_readiness.py::test_pricing_structure_without_amounts_and_offer_draft` |
| Implementation | Migration 0199 (`pricing_plan_item`), `mhvp.platform.market_readiness` (`GET /platform/pricing`, `POST /platform/pricing/items`, `PATCH /platform/pricing/items/{id}`, `GET /platform/pricing/offer.pdf`), CRM-Seite `/plattform/preisliste` |
| Change reason | M27 Marktreife (Kapitel 18), 27.09.2026: Struktur aus `docs/plans/M27.md` umgesetzt, Betragspflege beim Betreiber belassen |

## Regeln

- Die Struktur wird beim ersten Aufruf mit Stufen S bis XL, fünf Zusatzmodulen und einer
  Testphase angelegt. Bezeichnungen und Einheitenbereiche sind Entwurf und änderbar
  (`docs/ASSUMPTIONS.md` A-064); kein Betrag wird gesetzt.
- Jede Zeile trägt `amount = NULL`, bis der Betreiber einen Betrag pflegt (`PATCH`, Feld
  `amount`, Löschen mit `clear_amount`). `GET /platform/pricing` liefert `complete = false`
  und `missing_amounts`, solange eine aktive Zeile ohne Betrag ist.
- Das Angebot ist ein PDF-Entwurf mit Wasserzeichen ENTWURF, nennt fehlende Beträge als offen
  und weist alle Beträge netto ohne Umsatzsteuer aus. Es wird nicht versendet und ist keine
  Willenserklärung; Freigabe eines Angebots durch die Geschäftsführung.
- Die Preisstruktur ersetzt nicht die Preisliste je Modul (`price_list_entry`) und die Lizenz
  je Mandant; beide bleiben unverändert (Entscheidung 24.09.2026).
