# M26-02a Mieterhöhung: Basisprüfungen nur rechnerisch, keine Zulässigkeitsaussage

| Field | Content |
| --- | --- |
| ID | M26-02a |
| Title | Prüfungen zu Modernisierung, Index und Staffel rechnen nur eingegebene Werte nach; die Plattform enthält keine gesetzlichen Prozentsätze oder Grenzen und erklärt nie, dass eine Erhöhung zulässig ist |
| Scope | `mhvp.letting` (Mieterhöhung, `basis_checks`, Feld `basis_data`), alle Mandanten; Mieterhöhungsschreiben bleiben Entwurf |
| Source status | Produktschutz. Das Quellenregister (Anhang C) enthält keine Normen zum Mietpreisrecht; fehlende Quelle bleibt in OPEN_QUESTIONS M26-02 offen. Werte werden mit Quelle vom Betreiber erfasst, Prüfhinweise sperren die Freigabe bis zur Klärung |
| Acceptance case | keiner in Anhang D; verwandt `docs/rules/M26-02.md`, `docs/rules/M26-BASIS-01-mieterhoehung-basen.md`, `docs/rules/M26-rent-law.md` |
| Implementation | `mhvp.letting.basis_checks` (Decimal, ROUND_HALF_UP auf Cent), Spalte `basis_data` am Mieterhöhungsvorgang |
