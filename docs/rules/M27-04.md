# M27-04 Eine Preisstruktur für Lizenzen, Angebot und Abrechnungsvorschau

| Field | Content |
| --- | --- |
| ID | `M27-04` |
| Title | Stufen nach Einheiten, Zusatzmodule und Testphase sind die einzige Quelle der Abrechnungsvorschau; ein vereinbarter Lizenzpreis hat Vorrang |
| Scope | `mhvp.platform.licensing` (`GET /platform/tenants/{id}/billing-preview`, `PATCH/DELETE /platform/price-list/{id}`, `PATCH /platform/licenses/{id}`, `POST /platform/licenses/{id}/end`), Tabelle `pricing_plan_item`, `license`, `price_list_entry`, Migration 0264 |
| Source status | Fachliche Umsetzung zu M27 (Betreiberentscheidung 13 a). Keine Rechtsregel. Beträge sind Betreiberentscheidung (M27-01-01), Umsatzsteuer und Rechnungsstellung der Lizenzentgelte sind offen |
| Acceptance case | keine in Anhang D; Tests `apps/api/tests/integration/test_p15_platform.py`, `test_m27_licensing.py` |
| Implementation | Preis je Lizenz: `license.price_per_unit` (vereinbart, beim Anlegen aus dem gültigen Preislisteneintrag übernommen) sonst Preisstruktur: Modul Kern nach Stufe (Einheiten des Zählers innerhalb min/max), andere Module nach Zeile `module_<modul>`. Fehlt der Betrag, wird die Zeile mit 0,00 EUR berechnet und die Vorschau als unvollständig gekennzeichnet. Testphase: ein Monat ist frei, wenn sein letzter Tag vor Lizenzbeginn plus `trial_days` liegt (Annahme A-P15-01). Der heute gültige Preislisteneintrag eines Nicht-Kern-Moduls schreibt den Betrag der Modulzeile; `price_list_entry` bleibt als Preisverlauf |
| Change reason | Lückenliste 30.09.2026, M27-04, Entscheidung 13 a |

## Regeln

- Die Migration überträgt je Nicht-Kern-Modul den heute gültigen Preislisteneintrag in `pricing_plan_item` (nur in leere Beträge) und den Kernpreis in alle aktiven Stufen ohne Betrag. Bestehende Lizenzpreise bleiben unverändert.
- Eine Lizenz wird nie gelöscht, sondern über `valid_until` beendet (Abrechnungsspur).
- Preislisteneinträge ändern nur Preis und Notiz; bestehende Lizenzen behalten ihren vereinbarten Preis.
- Berechnung netto: Einheiten mal Preis, gerundet auf 2 Stellen, mindestens der Mindestbetrag der Lizenz; Summe als Decimal.
