# AI18-02 Nicht sperrender Prüfhinweis zur Kaution

- ID: AI18-02 (Befund GAH-111, Welle 20)
- Geltungsbereich: Kautionen von Mietverträgen über Wohnungen (`unit_type` apartment), `GET/PUT /deposit-hint-settings`, Feld `limit_hints` in `DepositOut`
- Anforderungstyp: Offene Entscheidung (Rechtsanwalt, Gate G3; AI17-04), technisch vorbereitet, Produktschutz
- Quellenstatus Anhang C: Baustein Kaution genannt, Wortlaut und Werte nicht bestätigt
- Regel: Schalter `deposit_limit_hint_enabled` (Standard aus, Tabelle `deposit_hint_setting`, Migration 0443). Vergleichswerte konfigurierbar: `factor_months` (Standard 3) Monatsmieten der Zahlarten `rent_payment_codes` (Standard `rent`, also ohne Nebenkosten) zum Beginn der Kaution, `max_installments` (Standard 3). Überschreitung ergibt einen Hinweistext ohne Normzitat; Speichern wird nie verhindert.
- Rechenbeispiel: Miete 800,00 EUR, Faktor 3, Vergleichswert 2.400,00 EUR; Kaution 2.500,00 EUR in 4 Raten ergibt zwei Hinweise, 2.400,00 EUR in 3 Raten keinen.
- Abnahmefall: kein Anhang-D-Fall; Test `tests/integration/test_ai18_deposit_hint.py`
- Änderungsgrund: GAH-111
