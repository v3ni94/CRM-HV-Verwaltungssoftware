# M27-02 Freigabe G5: Nachweisliste je Mandant

| Field | Content |
| --- | --- |
| ID | `M27-02` |
| Title | G5 (Drittmandanten) bleibt geschlossen, bis alle acht Nachweise mit Dokument erledigt sind und der Superadmin den Freigabeantrag genehmigt |
| Scope | Alle Mandanten, nur Freigabestufe G5; Nachweise: Pentest-Bericht, Verfahrensdokumentation, AVV-Vorlage, Aufbewahrungsmatrix freigegeben, Restore-Übung protokolliert, Barrierefreiheitserklärung, Datenschutzinformation Portal, Rollen- und Rechtematrix (Export) |
| Source status | Keine Rechtsnorm im Quellenregister (Anhang C); Produktschutz nach Abschnitt 18.0 und ADR 0003. Inhalt und Prüftiefe der Nachweise (externe Prüfungen) bleiben Betreiberentscheidung (`docs/OPEN_QUESTIONS.md` M27-02) |
| Acceptance case | keine in Anhang D; Test `apps/api/tests/integration/test_m27_market_readiness.py::test_g5_stays_closed_until_evidence_complete_and_superadmin` |
| Implementation | Migration 0199 (`g5_evidence`), `mhvp.platform.market_readiness` (`GET /platform/tenants/{id}/g5-evidence`, `PUT .../g5-evidence/{code}`, `ensure_g5_release_allowed`), Hook in `mhvp.platform.routers._decide`, Fehlercode `MHVP-GATE-0005`, Anzeige in `GET /platform/tenants/{id}/readiness`, CRM-Seite `/plattform/freigabe-g5` |
| Change reason | M27 Marktreife (Kapitel 18), 27.09.2026: Nachweisliste als Voraussetzung für G5 statt reiner Anzeige |

## Regeln

- Status je Nachweis `open` oder `done`; `done` nur mit `document_id` eines Dokuments des
  Mandanten (Prüfung im RLS-Kontext des Mandanten). Jede Änderung erzeugt das Ereignis
  `g5_evidence.updated` mit altem und neuem Status.
- Die Genehmigung eines Antrags G5 (`_decide`) prüft zusätzlich zum Vier-Augen-Prinzip
  (M2-02): alle Nachweise erledigt und Genehmigender ist der Superadmin. Andernfalls
  `MHVP-GATE-0005`, der Antrag bleibt offen, das Gate geschlossen. Die Superadmin-Umgehung nach
  ADR 0011 bleibt unverändert (nur hinter Plattformschalter).
- Die Nachweisliste öffnet, schließt oder widerruft kein Gate. Ein späteres Zurücksetzen eines
  Nachweises schließt G5 nicht automatisch; der Widerruf läuft über den Antrag.
- Keine Ausnahme für Jobs, Importe oder Integrationen: sie nutzen denselben Gate-Resolver.
