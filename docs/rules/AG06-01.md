# Bewertung abgeschlossener Aufträge durch Verwaltung und Bewohner (AG06, GAF-35)

| Field | Content |
| --- | --- |
| ID | AG06-01 (GAF-35, Entscheidungsfrage AE30-02) |
| Title | Bewertung eines abgeschlossenen Auftrags je Partei (Verwaltung, Bewohner), Anzeige nur gemäß Schalter `provider_rating_display` (off, staff, all) |
| Scope | `POST /work-orders/{id}/rating` und `GET /work-orders/{id}/rating` (Verwaltung), `POST` und `GET /portal/work-orders/{id}/rating` (betroffener Bewohner), Tabelle `work_order_rating` (Migration 0424), Auftragsseite im CRM, Meldungsseite im Portal |
| Source status | Abschnitt 14 (Dienstleister, Phase 4). Anhang C enthält keine Quelle; Produktschutz, keine Rechtsregel. Wer Bewertungen sehen darf, ist die offene Entscheidung AE30-02 (Datenschutz, G5) |
| Requirement type | Produktschutz, Offene Entscheidung (AE30-02) |
| Acceptance case | keiner in Anhang D; `apps/api/tests/integration/test_ag06_work_order_rating.py` (409 vor Abschluss und bei Doppelbewertung, 422, 403, 404 anderer Mandant, Anbieter und fremder Bewohner 404, Schalter), Frontend `WorkOrderRating`, `WorkOrderRatingPanel` |
| Rule | Bewertet werden kann ein Auftrag im Status done, invoiced oder accepted (sonst 409). Je Auftrag und Partei (staff, resident) gibt es genau eine Bewertung (Sterne 1 bis 5, Freitext höchstens 2.000 Zeichen); eine zweite wird mit 409 abgelehnt, eine gespeicherte Bewertung wird nie überschrieben (Eindeutigkeit je Mandant, Auftrag, Partei). Bewohner bewerten nur Aufträge, von denen sie betroffen sind (Initiator der Meldung oder Bewohner der Einheit); Dienstleister und fremde Bewohner erhalten 404. Die Bewertung bucht nichts und löst keine Zahlung aus |
| Rule, Anzeige | `off` (Standard): Die Verwaltung sieht keine Bewertungen, nur den Hinweis, ob sie selbst bewertet hat; der Bewohner sieht nur seine eigenen Sterne. `staff`: die Verwaltung sieht die Bewertungen am Auftrag (mit Freitext) und die Übersicht je Dienstleister (Anzahl, Durchschnitt, Verteilung, ohne Freitext). `all`: zusätzlich sieht der Bewohner im Portal Anzahl und Durchschnitt des Dienstleisters, nie Freitexte oder Einzelbewertungen. Der Dienstleister erhält in keinem Modus eine Bewertung. Die Übersicht je Dienstleister zählt die Bewertungen aus `work_order_rating` und die älteren Sterne am Auftrag |
| Change reason | Lückenbefund GAF-35 (Welle 18, AG06); Entscheidung AE30-02 bleibt offen, Variante A (intern) ist Standard |
