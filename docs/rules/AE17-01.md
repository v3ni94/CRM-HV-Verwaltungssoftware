# AE17-01 Umlagevereinbarung je Mietvertrag und Kostenposition mit Prüfbericht

| Field | Content |
| --- | --- |
| ID | `AE17-01` (ergänzt `M17-01`) |
| Title | Erfassung der Umlagevereinbarung je Mietvertrag und Betriebskostenart (Klauselbezug, Nachweisdokument, Gültigkeit), Massenerfassung je Objekt, Prüfbericht fehlender Grundlagen vor der Ausgabe der Abrechnung |
| Scope | `mhvp.contracts.allocation_routers` (`/contracts/{id}/allocation-agreements`, `POST /properties/{id}/allocation-agreements/bulk`), `mhvp.billing.allocation_basis` und `allocation_basis_routers` (`GET /statements/{id}/allocation-basis-report`, `GET/PUT /billing/allocation-basis-setting`), Tabelle `allocation_agreement`, Spalte `tenant_settings.allocation_basis_block` (Migration 0373). Mietabrechnungen aller Mandanten |
| Source status | Fachliche Umsetzung und Produktschutz. Rechtsgrundlage nur als Orientierung: § 556 Abs. 1 BGB (Umlagevereinbarung im Mietvertrag, Quellenregister R06). Geprüft wird nur das Vorhandensein einer erfassten Vereinbarung mit Klauselbezug, die den Mietzeitraum abdeckt, nicht die rechtliche Wirksamkeit der Klausel. Prüfschema je Kostenart bleibt offen (OPEN_QUESTIONS M17-01), technisch vorbereitet (Welle 16, AE17) |
| Acceptance case | keine in Anhang D. Tests `apps/api/tests/integration/test_ae17_allocation_agreements.py` (Anlage, Überlappung 409, Validierung 422, Leserecht 403, anderer Mandant 404, Massenerfassung mit Vorschau, Bericht fehlend, teilweise, vollständig, ausgeschlossen, Blockade von Statuswechsel und Informationsblatt, Schalter aus) |
| Implementation | Je Vertrag und Katalogart keine überlappenden Zeiträume (Ausschlussbedingung). Status `agreed` (Klauselbezug Pflicht) oder `excluded` (ausdrücklich nicht umlagefähig, blockiert nicht). Bericht je Kostenposition und Mietvertrag der Periode: fehlt, Zeitraum nur teilweise gedeckt, Kostenkonto ohne Betriebskostenart (nichts wird aus Kontonamen abgeleitet). Mandantenschalter `allocation_basis_block` (Standard an): bei Lücken sind Statuswechsel nach issued, due, posted sowie das Ablegen des Informationsblatts mit Code MHVP-BILL-0015 gesperrt. Beides bleibt hinter G3. Massenerfassung überschreibt nie, Vorschau ist Standard. Löschen nur, wenn keine begonnene Abrechnung den Zeitraum nutzt |
| Change reason | Priorität 17 des Betreibers (01.10.2026), Befund M17-01: je Position fehlte die erfasste Grundlage |
